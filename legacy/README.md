# Legacy site

The first NPG website build, preserved verbatim as of 2026-07-28. **Not maintained.**
Kept for reference — brand assets, established copy, and confirmed business facts —
not as a base to build on.

## Contents

| Path | What it is |
| --- | --- |
| `index.html` | Home page |
| `bio.html` | About / bio |
| `work.html` | Work |
| `contact.html` | Contact |
| `styles/main.css` | Full stylesheet for the four pages above |
| `scripts/main.js` | Page behaviour |
| `assets/npg-logo.png` | Logo master, 3508×2481 |
| `assets/npg-mark.png` | Monogram only — use at header sizes |
| `assets/npg-lockup.png` | Full trimmed lockup — larger placements only |
| `NPG-website-draft.html` | Earlier single-file draft, superseded by the four pages |

All paths are relative, so it renders standalone. Serve this directory over HTTP
rather than opening via `file://`.
